# Ma 3e — V3

Application PWA responsive pour GitHub Pages.

## Mise en ligne
1. Créer un dépôt GitHub.
2. Déposer **le contenu du dossier `ma-3e-app` à la racine du dépôt**.
3. GitHub → Settings → Pages.
4. Source : Deploy from a branch.
5. Branche : `main` / dossier `/root`.
6. Enregistrer.

## Contenu
- Accueil dynamique vert dominant
- Agenda
- Parcours : vie de classe, orientation, DNB, stage, certifications
- Espace de documents individuels (maquette)
- Responsive mobile / tablette / ordinateur
- PWA installable

Cette version est une interface front-end. L'authentification, les documents réellement privés et la synchronisation Apple nécessiteront un backend sécurisé dans une étape suivante.
